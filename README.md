# Руководство пользователя: «Пользовательские группы»

Приложение позволяет пользователям Nextcloud самостоятельно создавать группы, управлять их составом, делегировать административные полномочия и контролировать доступ к совместным ресурсам без постоянного участия системного администратора.

---

## 1. Матрица ролей и прав доступа

В приложении действует ролевая модель разграничения прав:

| Возможность | Владелец (Owner) | Управляющий (Manager) | Модератор (Moderate) | Участник (Member) | Администратор Nextcloud |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Создание новых групп** | — | — | — | — | Да (или разрешённые пользователи) |
| **Переименование группы** | Да | Да | Нет | Нет | Да |
| **Удаление группы** | Да | Нет | Нет | Нет | Да |
| **Передача владения группой** | Да | Нет | Нет | Нет | Да |
| **Добавление/удаление участников** | Да | Да | Да | Нет | Да |
| **Предложение кандидата (заявка)** | — | — | — | Да | — |
| **Одобрение/отклонение заявок** | Да | Да | Да | Нет | Да |
| **Делегирование прав («Управление»)** | Да | Нет | Нет | Нет | Да |
| **Делегирование прав («Модерация»)** | Да | Да | Нет | Нет | Да |
| **Просмотр общих ресурсов группы** | Да | Да | Нет | Нет | Да |
| **Просмотр журнала действий (аудит)** | Да | Да | Нет | Нет | Да |
| **Просмотр истории заявок** | Да | Да | Да | Нет | Да |

## 2. Создание группы

> [!NOTE]
> Возможность создания групп доступна администраторам Nextcloud, а также пользователям/группам, которым администратор предоставил доступ в настройках приложения.

1. В левой боковой панели нажмите кнопку **«+ Создать группу»**.
2. В появившемся окне укажите:
   - **Название группы** — отображаемое понятное имя (например, `Отдел маркетинга`).
   - **Чекбокс «Добавить себя как участника группы»**:
     - *Включён (по умолчанию)* — вы будете добавлены в список участников создаваемой группы.
     - *Выключен* — группа создастся с вами в качестве Владельца, но вы не будете занимать место в списке её рядовых участников (при этом сохраняя полный контроль).
3. При необходимости через строку поиска найдите и добавьте первоначальных участников группы кнопкой **«+ Добавить»**.
4. Нажмите **«Создать группу»**.

## 3. Управление участниками группы

### 3.1. Быстрое добавление участника
*(Доступно: Владельцу, Управляющему, Модератору, Администратору)*
1. Выберите группу в боковом списке.
2. В верхней панели действий нажмите кнопку **«Добавить участника»**.
3. В поле поиска начните вводить имя или логин пользователя.
4. Выберите пользователя из выпадающего списка и нажмите **«Добавить»**. Пользователь мгновенно включается в группу.

### 3.2. Редактирование списка и удаление участников
*(Доступно: Владельцу, Управляющему, Модератору, Администратору)*
1. Нажмите кнопку **«Редактировать группу»**.
2. В блоке «Участники группы»:
   - Для добавления: воспользуйтесь поиском и кнопкой **«+ Добавить»**.
   - Для удаления: найдите участника в списке ниже и нажмите кнопку **«- Удалить»**.
3. Нажмите кнопку **«Сохранить»** для применения изменений.

> [!IMPORTANT]
> **Особенности удаления себя из группы:**
> - **Владелец группы** может удалить себя из списка участников без потери контроля над группой.
> - **Управляющий или Модератор**, удаляя себя из участников, увидит окно предупреждения. При подтверждении и сохранении формы пользователь исключается из группы, а его **делегированные права автоматически отзываются**.

### 3.3. Подача и рассмотрение заявок на вступление
- **Для обычных участников группы**: участник может нажать кнопку **«Предложить участника»**, выбрать коллегу и отправить заявку.
- **Для Владельца / Управляющего / Модератора**:
  - На главной странице группы в блоке **«Запросы на рассмотрение»** отображаются активные заявки с указанием, кто и когда предложил кандидата.
  - Нажмите **«Принять»** (пользователь добавится в участники) или **«Отклонить»**.
  - Полная история всех обработанных заявок доступна по кнопке **«История запросов»**.

## 4. Переименование и передача прав на группу

### 4.1. Переименование группы
*(Доступно: Владельцу, Управляющему, Администратору)*
1. Нажмите кнопку **«Редактировать группу»**.
2. Измените текст в поле **«Название группы»**.
3. Нажмите кнопку **«Сохранить»**. Название мгновенно обновится в приложении и в адресной книге Nextcloud.

### 4.2. Передача владения группой
*(Доступно: только Владельцу и Администратору)*
1. Нажмите кнопку **«Редактировать группу»**.
2. Внизу окна нажмите кнопку **«Передать права владельца»**.
3. Выберите из списка участника, которому передаются права, и подтвердите передачу.
4. Новый пользователь станет владельцем группы со всеми исключительными правами (включая удаление группы).

## 5. Делегирование полномочий управления

*(Доступно: Владельцу и Управляющему)*

Если Владельцу группы требуется распределить обязанности по ведению группы:

1. В верхней панели группы нажмите кнопку **«Делегирование»**.
2. В секции **«Назначить права участнику»**:
   - Выберите участника из выпадающего списка.
   - Выберите уровень полномочий:
     - **«Модерация»** *(может назначать как Владелец, так и Управляющий)* — право одобрять/отклонять заявки кандидатов, добавлять и удалять участников.
     - **«Управление»** *(может назначать только Владелец)* — полный контроль за исключением удаления группы и передачи владения.
   - Нажмите **«Назначить»**.
3. Для отзыва полномочий: в блоке «Назначенные права» нажмите красную кнопку **«Отозвать»** напротив нужного пользователя.
4. Нажмите кнопку **«Сохранить»**.

---

## 6. Дополнительные возможности

- **Общие ресурсы группы** *(кнопка «Общие ресурсы»)*:
  - Позволяет Владельцу и Управляющим просматривать все файлы и папки Nextcloud, к которым группе был предоставлен общий доступ.
  - При необходимости можно в один клик отозвать доступ группы к неактуальному ресурсу.
- **Журнал действий** *(кнопка «Журнал действий»)*:
  - Доступен Владельцу и Управляющим. Ведёт подробный аудит событий: когда группа была создана, переименована, кто был добавлен или удалён, кому выданы или отозваны права.
- **Удаление группы** *(кнопка «Удалить группу»)*:
  - Доступно исключительно Владельцу и Администратору Nextcloud.
  - Безвозвратно удаляет группу и аннулирует групповые доступы к файлам.
